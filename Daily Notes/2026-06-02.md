## A.1 Chapter 1
### A.1.1 thinking rationally
- if premises are true, conclusion must be true
- start of formal logic.
#### A.1.1.1 Premises
- Facts:
	- `parent(john, mary)`
	- `parent(john, tom)`
	- `parent(mary, alice)`
	- `parent(tom, bob)`
- Rule:
	- X is a grandparent of Z if X is a parent of Y and Y is a parent of Y and Y is a parent of Z
	- `grandparent(X, Z)`
	- `parent(X, Y)`
	- `parent(Y, Z)`
- `grandparent(john, X)`

- This approach ran into major issues:
		a. Hard to turn human knowledge into formal logic because real-world knowledge is incomplete, uncertain and vague.
		b. Solving logical problems can be too slow even if the rules are correct, the search for a solution can explode.
- So "in principle " reason is not always useful in real life.

- An agent is anything that acts on its own and works toward goals.
- A rational agent chooses the action that leads to the best result, or the best expected result when things are uncertain.
- Logical reasoning can help an agent, but rational action is not only about logic.
- The rational-agent approach is broader than the "laws of thought" approach.

### A.1.2 Knowledge
- Knowledge is information, understanding and skills acquired through experience or education.
- Knowledge can be:
	- Explicit knowledge: Easily documented and shared (books, manuals).
	- Tacit knowledge: Personal, experience-based, hard to formalize.
- The meaning of knowledge is closely related to the meaning of intelligence.
- Intelligence requires the possession of an access to knowledge and a characteristic of intelligent people is that they possess much knowledge.
- In modern AI especially in machine learning and deep learning knowledge representation has shifted from explicit, symbolic forms (like rules, semantic networks, frames and ontologies) to implicit, learned representations.

### A.1.3 Learning
- Types of machine learning:
	- supervised learning
	- unsupervised learning
	- reinforcement learning
- Learning enables AI to adapt and improve over time.

## A.2 Chapter 2
### A.2.1 Introduction to Agents:
- An agent is anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators.
- A software agent receives keystrokes, file contents and network packets as sensory inputs and acts on the environment by displaying on the screen writing files and sending network packets.

### A.2.2 PEAS Description of Agents
- For the acronymically minded, we call this PEAS (Performance, Environment, Actuators, Sensors) components.

### A.2.3 Environment Types:
- There are many different environments in which AI agents can work.
- Instead of studying each environment separately, AI researchers classify environments using a small number of dimensions (characteristics).
- Discrete/Continuous: If there are a limited number of distinct, clearly defined ,states of the environment, the environment is discrete otherwise continuous.
- Observable/ Partially Observable: If it is possible to determine the complete state of the environment at each time point from the percepts it is observable otherwise it is only partially observable.
- Static/Dynamic: If the environment doesn't change while an agent is acting, then it is static; otherwise it is dynamic.
- Single/Multiple agent: The environment may contain otgher agents which may be of same or different types.
- Deterministic/ Stochastic: 
- Episodic/Non-episodic: In an episodic environment, each episode consists of the agent perceiving and then acting.
	- for eg, an agent that has to spot defective parts on an assembly line bases each decision on the current part, regardless of previous decisions.

### A.2.4 Rational Agents
What is rational at any given time depends on four things:
- The performance measure that defines the criterion of success.
- The agent's prior knowledge of the environment
- The actions that the agent can perform.
- The agent's percept sequence to date.

### A.2.5 Structure of agents
#### A.2.5.1 Simple reflex agents
- Memoryless
- " If this happens, do that."
- Uses current percept only.
- No memory of the past.
#### A.2.5.2 Model Based reflex agents
- "Remember what I have seen before."
- Maintains an internal state (memory).
- Useful when environment is partially observable.
#### A.2.5.3 Goal based agents
- "What action will help me reach my goal?"
- Has a goal to achieve.
#### A.2.5.4 Utility-based agents
- "Which option is the best among many possible options?"
- Uses a utility measure.
- Chooses the actions with the highest expected benefits.
